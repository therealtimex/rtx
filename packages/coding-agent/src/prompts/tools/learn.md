Capture reusable lessons in long-term memory; optionally mint/enhance a managed skill in the same call.

Use after solving insight likely to pay off again: a non-obvious fix, discovered project convention, or workflow that worked.

`skill` optional; provide only for a repeatable procedure worth codifying as `SKILL.md`, not a fact. Managed skills: isolated `~/.rtx/agent/managed-skills`; surfaced as normal skills next session; NEVER touch user-authored skills. `body` is the SKILL.md content in markdown, no frontmatter — frontmatter is generated from `name` and `description`. Use `action: "update"` to enhance an existing managed skill.

Capture sparingly, specifically: one strong reusable lesson > several vague ones.
